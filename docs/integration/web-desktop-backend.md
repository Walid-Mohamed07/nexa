# Integration overview

This document is the shared contract reference for the web app, backend, and desktop app.

## Goals

- Keep API, domain, and database language consistent
- Avoid guessing across teams
- Support mock-first delivery and parallel work

## Shared conventions

- Use `/api/v1`
- Use `data` + `meta` envelopes
- Use a consistent error format
- Use stable shared enums
- Use a common order lifecycle
