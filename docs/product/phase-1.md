# Phase 1 scope

The first phase establishes the shared contract and shell of the platform.

## Included

- Customer journey definition
- Domain model and lifecycle conventions
- Shared enums and entity definitions
- OpenAPI 3.x contract
- Mock API with realistic café data
- Minimal Next.js customer app connected to mock API
- Integration documentation for backend and desktop teams
- Future phase roadmap

## Not included

- Full loyalty engine
- Full recommendation engine
- AI features
- Production payment integrations
- Complex Google sync
- Full SaaS subscription billing
- Full analytics platform

Phase 1 is intentionally limited to the foundation required for parallel delivery without guesswork.
